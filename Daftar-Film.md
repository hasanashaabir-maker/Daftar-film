# Daftar film saya 

 Web sederhana untuk merating film yang sudah ditonton

 ## Fitur
 - Tambah film dengan judul
 - Urutkan berdasarkan rating
 - Hapus film
 - Data tersimpan di browser(tidak hilang saat halaman ditutup)

 ## Cara pakai 
 1. Unduh project ini 
 2. Buka file index.html dengan browser (klik dua kali)

 ## Teknologi
HTML,CSS, dan JavaScript
